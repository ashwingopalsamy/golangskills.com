# Engineering Skills for Go

This collection owns Go language and API decisions, network adapters, verification, performance diagnostics, application security, service operations, and general engineering review.

It contains:

- `go-language-engineering`
- `go-project-and-api-design`
- `go-service-boundaries`
- `go-testing-and-verification`
- `go-performance-and-diagnostics`
- `go-security-hardening`
- `go-production-operations`
- `review-go-engineering-change`

The collection deliberately stops at distributed transaction schedules, broker delivery, leases, monetary invariants, and payment lifecycles. Those activate the distributed-systems or fintech collections.

Canonical skills live under `skills/`. Generated Codex, Claude Code, Cursor, and OpenCode layouts must never be edited directly.
