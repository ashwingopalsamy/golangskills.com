# Evaluation harness

Every skill ships public development cases. The current corpus contains 80: one positive route, one confusion negative, and two quality scenarios per skill. Quality cases name expected invariants, forbidden outcomes, deterministic graders, and optional semantic rubrics. Twelve cases use executable fixtures for races, lifecycle completion, HTTP bodies, ambiguous commits, redelivery, retry amplification, API compatibility, fuzz regressions, rounding, ledger balance, payment ordering, and settlement netting.

`skillctl eval run` creates one temporary project and ephemeral session per case. It installs no skills for baseline, the selected arm for treatment, randomizes order from a recorded seed, assigns an opaque arm label, records client/model/commit/grader metadata, captures raw runner JSONL, and resumes already completed cells. `-case skill-id/case-id` reruns an affected cell without restarting the arm.

`skillctl eval matrix` selects the same canonical cases for baseline, this project, and every frozen competitor, then globally randomizes all arm/case cells. Each arm receives a distinct deterministic opaque label. `-fixtures-only` selects the 12 executable cases; `-explicit` switches every arm to explicitly matched skills; and `-repetition N` makes repeat identity part of resumability. A mixed score artifact is reported with `-arm`; `-arm ours -against-arm gophers` performs an in-file paired comparison.

For this collection, a positive routing case expects its owning skill and a confusion-negative case accepts only its declared neighboring skill IDs. Competitor arms use a committed canonical-to-arm `-skill-map`; a case-specific `-routing-map` can override ambiguous mappings. Missing mappings fail closed. Baseline expects `NONE`. Isolated plugin namespace prefixes are normalized without weakening the expected skill ID. This separates arm-specific naming from prompt difficulty and prevents correct neighboring routes from being scored as false failures.

Fixture cells copy a locked failing Go module into the isolated workspace, enable workspace edits, run only allowlisted `go test` targets, and store the resulting Go sources plus grader output in raw JSONL. All 12 committed baselines fail their intended grader. Explicit competitor cells require a frozen canonical-to-arm `-skill-map`; missing mappings fail closed.

`eval score` applies accepted-route equality and deterministic response/fixture graders. `eval report` reports pass rate with a 95% Wilson interval, collection scores, routing macro-F1, unrelated-prompt false activation, client-reported token efficiency, and failures. With `-against`, it requires case-key pairing, assigns half credit to ties, bootstraps paired win-rate and mean-difference intervals, reports collection deltas, and classifies the score/input-token Pareto relation. A zero unrelated-case count means false-activation evidence is missing, not that the rate is zero. The harness does not turn keyword grading into a broad quality claim; executable fixtures and blinded rubrics are required for release evidence.

The post-freeze 10-case Codex routing screen at fixture commit `3365b98` scored ours 10/10, `cxuu-golang-skills` 7/10, `gophers` 6/10, `go-skills` 6/10, and `cc-skills-golang` 5/10. The additional specialist `golang-ddd-skills` arm, frozen later at fixture commit `115dc00`, scored 4/10 under the same prompts, seed, model, client, and scorer. Ours had zero critical misses; every competitor had at least one. The intervals are wide and overlap, so this is encouraging development evidence, not a superiority result. Raw and scored artifacts are retained under `evaluations/runs/` and `evaluations/scores/` with model, client, fixture, arm, and scorer versions.

The later complete public native-discovery routing matrix at fixture commit `2e26481` ran all 40 routing cases across seven globally randomized arms (280 cells) with no runner errors. Ours scored 38/40, macro-F1 0.9533, zero classified critical misses, and collection pass rates of 0.9375 engineering, 0.9167 distributed systems, and 1.0 fintech. Competitor pass rates ranged from 0.425 to 0.625; ours cleared the routing-only paired-win thresholds against every skill competitor. The [ours arm report](../evaluations/reports/development/full-routing-ours.json) and [paired reports](../evaluations/reports/development/) link to the [raw matrix](../evaluations/runs/2026-08-18-full-routing-matrix-native.jsonl) and [scores](../evaluations/scores/2026-08-18-full-routing-matrix-native.jsonl). This remains development evidence: it has no unrelated holdout prompts, and the no-skill arm's correct `NONE` choices are not behavioral baseline-improvement evidence.

One reconciliation fixture also passed end to end, including stored edited source and `go test` output. The [raw fixture cell](../evaluations/runs/2026-08-18-ours-reconciliation-fixture.jsonl) and [fixture score](../evaluations/scores/2026-08-18-ours-reconciliation-fixture.jsonl) remain development evidence.
