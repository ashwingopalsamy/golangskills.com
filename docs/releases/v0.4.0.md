# Go plugin family v0.4.0

Version 0.4.0 coordinates three non-overlapping Go plugin collections under one recognizable public family:

- **Go: Production Engineering** for language, APIs, services, testing, diagnostics, performance, security, operations, and general engineering review;
- **Go: Distributed Systems** for concurrency lifecycles, consistency, messaging, resilience, coordination, and distributed-change review;
- **Go: Fintech** for money, ledgers, payment lifecycles, financial idempotency, settlement, reconciliation, security, compliance, and fintech-change review.

Stable package IDs and all canonical skill IDs are unchanged. The release adds collection-specific CC0 Gopher artwork, collection-specific capabilities and starter prompts, more precise mixed-domain routing cases, generated ChatGPT/Codex, Claude Code, Cursor, and OpenCode packages, and refreshed catalogs and discovery data.

Routing follows specialist precedence: financial-integrity work routes to Go: Fintech; cross-process consistency and partial-failure work routes to Go: Distributed Systems; general Go engineering routes to Go: Production Engineering. Metadata is intentionally descriptive rather than keyword-stuffed.

This release makes no category-leadership or cross-agent behavioral-superiority claim. The larger repeated comparison remains deferred to the release-candidate benchmark batch.
