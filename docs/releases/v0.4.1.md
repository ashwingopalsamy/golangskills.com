# Go plugin family v0.4.1

Compatibility and packaging update for Go 1.27.

## Go 1.27 support

- All 20 skills now list Go 1.27 in their current guidance.
- Go 1.24 remains the minimum supported version.
- Go 1.27 joins CI alongside the existing 1.24, 1.25, and 1.26 lanes.
- One-time workflow and Agent Skills checks run only on the Go 1.27 lane, keeping validation coverage broad without multiplying the expensive bits.

## Surface refresh

- Regenerated catalogs, plugin metadata, and Cursor/OpenCode adapters from the canonical `skills/` tree.
- Updated deterministic-concurrency guidance for Go 1.27.
- No new evaluation campaign was introduced.

## Compatibility

Go 1.24 or newer. Current guidance targets Go 1.25, 1.26, and 1.27. See [compatibility.md](../compatibility.md) for client and package details.
