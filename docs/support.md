# Support

Use [GitHub Issues](https://github.com/ashwingopalsamy/golangskills.com/issues) for installation problems, incorrect guidance, security-sensitive false positives, missing Go coverage, and reproducible agent-routing failures.

Include the plugin name and version, client and model, Go version, sanitized prompt, expected invariant, and observed result. Do not post credentials, proprietary source code, payment data, personal data, private benchmark holdouts, or other secrets.

For a suspected vulnerability that should not be public, use the repository's GitHub Security Advisory reporting channel instead of a public issue.
