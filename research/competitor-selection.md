# Additional competitor selection

The release comparison set was refreshed on 2026-08-18 using public searches for Go-specific Agent Skills collections. A candidate had to be public, installable, contain multiple Go skills, support at least two target clients, and add material coverage not already represented by the four supplied general-purpose collections.

[`joeyave/golang-ddd-skills`](https://github.com/joeyave/golang-ddd-skills) was selected as the additional specialist arm. At the freeze it provided five MIT-licensed, cross-client Go skills covering service architecture, domain refactoring, CQRS, and infrastructure. This makes it a useful architecture specialist comparator; the project does not describe it as the most popular or broadest Go collection.

The immutable commit, complete file inventory, license, material-item hashes, and skill inventory are recorded in `research/corpus-lock.json`. Canonical-to-arm mappings live in `evaluations/arms/golang-ddd-skills.skill-map.json`. Search results and popularity are time-varying discovery inputs, not benchmark scores.
